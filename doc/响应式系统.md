# 构建一个基础的响应式系统

- 我们先创建一个项目

```bash
pnpx create-vite
选择 vanilla - Javascript (原生js项目)
pnpm i
pnpm dev
```

Vue3 使用 Proxy 拦截对象的操作，实现响应式，大致思路就是创建一个桶，里面存放一个树形结构的数据，结构是：

```text
target: 响应式对象
  - key: 对象的属性
    - effect: 要监听的副作用函数
```

在 Proxy 的 get 拦截器中，我们往桶里塞 effect，在 set 中，我们取出 effect 并执行

- 修改`main.js`

```js
import "./style.css";

const obj = { text: "hello" };

// 存放 target => key => effect
const bucket = new WeakMap();

let activeEffect;
const effect = (fn) => {
  activeEffect = fn;
  fn();
};

// 往桶里塞effect
const track = (target, key) => {
  if (!activeEffect) return;
  let depsMap = bucket.get(target);
  if (!depsMap) {
    bucket.set(target, (depsMap = new Map()));
  }
  let deps = depsMap.get(key);
  if (!deps) {
    depsMap.set(key, (deps = new Set()));
  }
  deps.add(activeEffect);
};

// 取出effect并执行
const trigger = (target, key) => {
  const depsMap = bucket.get(target);
  if (!depsMap) return;
  const deps = depsMap.get(key);
  deps && deps.forEach((fn) => fn());
};

const proxy = new Proxy(obj, {
  get(target, key) {
    // get的时候做track，也就是把effect func添加到桶里
    track(target, key);
    return Reflect.get(target, key);
  },
  set(target, key, value) {
    Reflect.set(target, key, value);
    // set的时候做trigger,也就是执行 effect func
    trigger(target, key);
    return true;
  },
});

effect(() => {
  document.body.innerText = proxy.text;
});

setTimeout(() => {
  proxy.text = "bye";
}, 1000);
```
